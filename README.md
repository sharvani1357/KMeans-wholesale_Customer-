# 🟢 Customer Segmentation Dashboard

This Streamlit application uses **K-Means Clustering** to segment wholesale customers
based on their purchasing behavior.

## 🎯 Objective
- Identify hidden customer groups
- Understand buying patterns
- Support business decisions like marketing and inventory planning

## 📊 Features
- Interactive feature selection
- Dynamic cluster visualization
- Cluster-wise summary statistics
- Business-friendly interpretations

## 🗂 Project Structure
- ├── app.py
- ├── requirements.txt
- ├── README.md
- └── data/
- └── raw/
- └── Wholesale customers data.csv


## ▶️ How to Run

- pip install -r requirements.txt
- streamlit run app.py
### 📌 Note
- Customers grouped into the same cluster show similar purchasing behaviour
and can be targeted using similar business strategies.
